# Cérebro do Projeto - Agendas & Manutenção

Bem-vindo à base de conhecimento do projeto!
Esta pasta (`/docs`) foi estruturada para ser utilizada como um Vault do **Obsidian**.

## Estrutura Atual
- `ADRs/` - Registros de Decisão de Arquitetura (Architecture Decision Records). Por que escolhemos X ou Y.
- `Arquitetura/` - Como o código está organizado (MVC, Componentes, Services).
- `Banco_de_Dados/` - Esquema e tabelas do Supabase.
- `Regras_Negocio/` - Lógicas de negócio (ex: como o OCR funciona, regras de chamados).

## Como usar com o Obsidian
1. Abra o Obsidian.
2. Clique em "Open folder as Vault".
3. Selecione a pasta `/docs` do projeto.
4. Comece a criar links bi-direcionais como `[[Nome_do_Arquivo]]` entre os documentos.
